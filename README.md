# Daily Planner

A simple, minimalist iOS app for organizing your daily tasks.

## Why I Built This

I needed a way to organize my day. For a long time, I used Excel spreadsheets, but I wanted something more accessible - something I could check from anywhere.

I tried many existing apps, but they were either too complex or required a paid subscription. All I wanted was a simple tool that helps me plan my day without overwhelming me.

So I built this app. No complexity, no paywalls - just a straightforward daily planner that works.

I hope people use it and find it helpful. Nothing would make me happier.

## Features

- Clean, minimalist interface
- Timeline view for daily tasks
- Easy task management
- Free and open source

## Tech Stack

- SwiftUI
- iOS 17+
